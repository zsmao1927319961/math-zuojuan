〇 总工作流：任何长难句四步走

1
找谓语动词（时态词 / am·is·are / do·does…），有几个谓语就有几个分句。
2
圈修饰块：从句、介词短语、分词短语——先括起来，不硬翻。
3
草稿：按英语语序把各块直译出来。
4
重排：按中文习惯调整——状语提前、被动转主动、长定语拆小句。
“不会翻译”九成卡在第 2 步认不出句型 → 下面每个句型都给识别信号和翻译公式。

一、修饰语家族（出现率最高）

句型识别信号翻译公式例句（2014 T3）
of 后置定语名词 + of + 名词/短语短的：B 的 A；of 链超过两层就拆句the concept of man versus machine → 人机对抗的概念
定语从句（短）that / which / who + 谓语，一层意思前置：“……的” + 名词jobs that were once thought to be immune from automation → 曾被认为不受自动化影响的工作
定语从句（长）从句里还套从句 / 介词短语后置拆译：先译名词，再“它 / 该……”另起小句25 词以上的从句别硬前置
同位语从句fact / idea / notion that + 完整句“这一观点：……” 或用冒号引出the fact that machines replace jobs → 这一事实：机器取代岗位
分词作定语名词后接 doing / donedone 前置“被……的”；doing 前置“正在……的”jobs facing automation → 面临自动化的工作

二、状语与语序家族

句型识别信号翻译公式例句
时间 / 条件从句When / If / Once / As 开头中文提前：“当……时 / 一旦…… / 如果……”When there is rapid improvement… → 当技术迅速改进时
让步Although / While / Even if“尽管……但……”（中文的“但”必须补出来）—
原因because / for“因为…… / 原因在于……”—
插入语两个逗号 / 破折号之间，删掉后句子仍完整先跳过找主干，最后塞回we are right now simply experiencing… → 先抓 we are experiencing

三、被动语态家族（考研翻译第一高频）

信号公式例
be thought / said / believed to do“人们认为 / 据说……”jobs thought to be immune → 人们认为不受影响的工作
be + done，无施动者“受到 / 得到 / 为……所”become threatened → 受到威胁
be + done + by X保留施动者：“被 X……”—
It is + done + that“据…… / 人们……”It is widely accepted that → 人们普遍认为

四、特殊结构家族

句型公式例句
形式主语 itIt would be + adj + to do → “做……是……的”；would = 恐怕 / 未免（委婉语气）it would be a mistake to think… → 认为……那就错了
There be状语提前、修饰拆句、不死译“有”；抽象名词转动词（improvement → 改进）When there is rapid improvement in… → ……迅速改进时
as…as 家族at least / almost / nearly + as…as = “至少 / 几乎和……一样”；not so much A as B = “与其说 B 不如说 A”at least as old as the industrial revolution → 至少和工业革命一样古老
more A than B“与其说 B，不如说 A”（重心在 A）—
倒装（Only if / Not only / 否定词开头）先还原正常语序再翻—
指代还原this / that / such + 名词 → 还原成前文内容（阅读题考点）this phenomenon = 人机之争这件事
语气副词simply / merely / just = “仅仅是”→ 暗含转折；would / could = 委婉推测we are simply experiencing… → 只不过是在经历……（言外之意：不止如此）

五、There be 专项小卡

  • 状语提前：There is a book on the desk → 桌上有本书。
  • 不死译“有”：remain → 仍存在；arise → 出现；emerge → 涌现。
  • 补泛指主语：There is no agreement → 人们没有一致看法；There is no denying that → 不可否认。
  • 抽象名词转动词：There is rapid improvement in X → X 迅速改进（考研翻译核心技巧）。
  • 写作反用：There is no denying that… / There is a growing tendency that… 是现成高分句型。

六、“完全翻不动”时的四个急救动作

1
找谓语：圈出所有动词，砍掉从句里的，剩下的就是主干“谁—怎么样”。
2
砍修饰：介词短语、从句、插入语全部括起来。
3
名词转动词：improvement → 改进、phenomenon → 出现……的现象（中文动词多，英文名词多）。
4
拆句保命：翻不顺就拆成两个短句——翻译扣分扣“错”，不扣“碎”。

七、练习闭环

  • 每天英语阅读只精翻 1 句，翻完发 ZCode 批改（按主干 / 修饰 / 语序三处批注）。
  • 每周日归档：把本周翻过的句子按本页句型表归类——表会越用越厚，句型就内化成条件反射。
